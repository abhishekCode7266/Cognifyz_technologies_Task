# Python Quiz Game

This repository contains a simple command-line multiple-choice quiz implemented in Python.

## Files

- `Cognifyz_task_software development/Basic text -based game.py` — A basic text-based Python quiz game that asks 10 multiple-choice questions and shows the final score and percentage.

## Requirements

- Python 3.6 or newer

## How to run

1. Clone the repository or download the script.
2. Open a terminal and navigate to the repository folder.
3. Run the game with:

```bash
python "Cognifyz_task_software development/Basic text -based game.py"
```

(If your shell does not like spaces in the filename or path, rename the file or run using the full quoted path.)

## How it works

- The script displays questions with four options (A/B/C/D).
- Enter the letter corresponding to your answer and press Enter.
- Enter `Q`, `QUIT`, or `EXIT` to stop the quiz early — the current score will be shown.
- At the end the script displays your final score, percentage, and a brief rating.

## Notes / Improvements

- Consider moving the script into a directory without spaces in the filename.
- You can add more questions by editing the `questions` list in the script.
- Potential improvements: support for categories, timed questions, reading questions from a JSON/YAML file.
